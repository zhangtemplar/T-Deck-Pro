# Screenshots

Placeholders referenced by the top-level README.

Most are device screenshots: press **Alt+P** on the screen you want and the
firmware writes a 1-bpp BMP into `/images` on the SD card. Pull them off with
the Files app (it serves the card over WiFi) and convert to PNG.

Two are not screenshots: `device.jpg` is a photograph of the hardware, and
`files.png` is a browser window on a laptop.

| File | Shows |
|---|---|
| `device.jpg`      | photo of the T-Deck Pro running this firmware |
| `home.png`        | home screen, app grid (page 1) |
| `gps.png`         | GPS overview — position, satellites, time |
| `map.png`         | map page — contours, scale bar, north arrow, position |
| `gps-track.png`   | tracker part-way through a recording |
| `map-picker.png`  | map chooser listing `/maps` |
| `reader.png`      | reader showing an EPUB chapter |
| `dict.png`        | a lookup with results from two dictionaries |

| `weather.png`     | current conditions |

| `clocks.png`      | six cities on page 1 |
| `clocks-map.png`  | page 2, world map timezone picker |

Worth capturing with real content rather than empty screens — an empty book
list or a dictionary with no results says very little about what the firmware
does.
